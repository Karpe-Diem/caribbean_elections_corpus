# Documentation

This directory will contain the corpus documentation, including its scope, collection methodology, ethical safeguards, access model, and version history.

## Codebook

The emoji-annotation codebook is excluded from version 1 and retained privately for further review. It may be added in a subsequent release.

A separate small annotated sample in `../data/annotated_sample/` will illustrate the application of final `primary_function` codes. Case-level `secondary_function` assignments, coder identifiers, pre-adjudication annotations, adjudication notes, and comment-level research files remain private.

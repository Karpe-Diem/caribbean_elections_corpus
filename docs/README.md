# Documentation

This directory will contain the corpus documentation, including its scope, collection methodology, ethical safeguards, access model, and version history.

## Public codebook

The [Emoji Annotation Codebook, version 1.18 public edition](CEC_codebook_v1.18_public.docx) provides the full coding procedure needed to apply and evaluate the annotation scheme. It includes the decision tree, operational definitions for all primary and secondary functions, boundary rules, reliability sampling procedure, and adjudication policy.

Dataset-derived examples are omitted from the codebook. A separate small annotated sample in `../data/annotated_sample/` will illustrate the application of final `primary_function` codes. It will be distinct from the main comment-ID corpus. Case-level `secondary_function` assignments, coder identifiers, pre-adjudication annotations, and adjudication notes remain private.

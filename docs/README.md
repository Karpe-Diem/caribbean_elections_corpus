# Documentation

This directory will contain the corpus documentation, including its scope, collection methodology, ethical safeguards, access model, and version history.

## Public codebook

The [Emoji Annotation Codebook, version 1.17 public edition](CEC_codebook_v1.17_public.docx) provides the full coding procedure needed to apply and evaluate the annotation scheme. It includes the decision tree, operational definitions for all primary and secondary functions, boundary rules, reliability sampling procedure, and adjudication policy.

Dataset-derived examples are omitted to reduce quotation traceability. Case-level `secondary_function` assignments, coder identifiers, pre-adjudication annotations, and adjudication notes remain private.
